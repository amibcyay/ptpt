Asking nicely

European Portuguese softens requests. Direct “I want…” is understood, but locals usually use the courtesy imperfect and a few set phrases.

Core idea
  • Use the imperfeito of querer, poder, precisar, gostar, preferir for polite requests — even though you are asking about now.
  • Add por favor or se faz favor.
  • Literal meaning is “I wanted / could…”; in context it means “I’d like / could you…”.

Direct → polite

Too bluntNatural EP
Quero um café.Queria um café, por favor.

Common courtesy forms

Queria uma mesa para dois. · Preferia um quarto mais calmo.
I'd like a table for two. · I'd prefer a quieter room.
Podia falar consigo? · Precisava de uma fatura.
Could I speak with you (formal)? · I'd need a receipt.

Other softeners

Era para…

Useful at counters and on the phone — “I’m here to…” / “I was hoping to…”:

Era para marcar uma consulta. · Era para levantar uma encomenda.
I was hoping to book an appointment. · I'm here to pick up a parcel.

Será que…?

Adds uncertainty — “I wonder if… / Would it be possible…?”:

Será que me pode ajudar? · Será que dá para pagar com cartão?
I wonder if you could help me? · Would it be possible to pay by card?

Importa-se de…? / Importas-te de…?

“Would you mind…?” — formal vs informal:

Importa-se de repetir? · Importas-te de fechar a janela?
Would you mind repeating? (formal) · Would you mind closing the window? (tu)

Please

  • Por favor — neutral, always safe
  • Se faz favor — very common in cafés and shops
Complaints: open with Desculpe / Lamento incomodar, hedge with parece que… / acho que…, then ask for a fix with podia… or será que….
