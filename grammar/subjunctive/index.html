Subjunctive (conjuntivo)

The conjuntivo handles doubt, emotion, hypotheticals, and many subordinate clauses. European Portuguese uses it more than English — learn common triggers (que, se, quando, para que).

B2

Common triggers (often + que)
  • Wish / emotion: Espero que… · É pena que…
  • Doubt / denial: Não creio que… · Talvez…
  • Hypothesis: Se tiver tempo… (future subjunctive)
  • Time / purpose: Quando chegares… · Para que saibas…

Present subjunctive (snapshot)

Espero que ele venha. · É importante que estudem. · Quer que eu fale?

Imperfect subjunctive

Hypothetical present/future or polite past: Se fosse rico, viajaria. · Gostaria que me dissessem a verdade.

Future subjunctive

After se/quando for a future condition: Se vieres, avisa. · Quando chegar, telefona.

Don't map English subjunctive 1:1 — focus on set phrases and triggers.
