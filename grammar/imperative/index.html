Imperative

Commands and requests use the imperativo. Affirmative tu forms are often irregular; negative commands use the present subjunctive for all persons.

Negative imperative

All persons use present subjunctive in negative commands:

Não fumes. · Não fale. · Não comamos tarde. · Não se preocupem.
Tip: Polite requests often avoid bare imperatives — use queria / podia or se faz favor.
